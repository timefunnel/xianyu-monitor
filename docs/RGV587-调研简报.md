# 闲鱼 RGV587_ERROR 技术简报

场景：Playwright 监听 `...pc.search`；55 轮正常，停机 8h 后**首次请求**即报错，App 同账号正常。

## 1. RGV587_ERROR / ::SM 是什么

它与 `FAIL_SYS_USER_VALIDATE` 成对出现，本质是**人机验证（punish/captcha）指令**。大麦下单被拦时 `ret` 同时含二者，并附 `data.url` 指向 `.../punish?x5secdata=...&x5step=2`（[Automatic_ticket_purchase#27](https://github.com/MakiNaruto/Automatic_ticket_purchase/issues/27)）；闲鱼自身接口 `mtop.taobao.idlemessage.pc.login.token` 被拦时结构相同、url 带 `action=captcha`（[xianyuapis#4](https://github.com/IAMLZY2018/xianyuapis/issues/4)）。所以它是 **baxia 风控要求过验证**；频率是最常见触发条件，但不宜归为纯限流，也**不是 `_m_h5_tk` 失效**（另报 `FAIL_SYS_TOKEN_EXPIRED`，[roundproxies](https://roundproxies.com/blog/m_h5_tk-solver/)）。社区归因集中在：频率过高（[52pojie](https://www.52pojie.cn/thread-1934425-1-1.html)、[CSDN](https://blog.csdn.net/weixin_44110940/article/details/140163813)）、缺 `bx-ua`/`bx-umidtoken` 头（#27）、cookie 与页面流程不匹配（[tickets#45](https://github.com/shiyutim/tickets/issues/45)）、环境被识别（[TSDK#18](https://github.com/xinlingqudongX/TSDK/issues/18)）、同 IP 连坐（[V2EX](https://www.v2ex.com/t/527879)）。

**推测**：停机 8h 后首个请求即失败而 App 同账号正常，不像频率，更像该 profile／出口 IP／网页端会话被标记。

## 2. 公开的处理办法与说法

- **重新登录／换浏览器登录**：维护者对同类报错的首要建议（[tickets#19](https://github.com/shiyutim/tickets/issues/19)），成功率无量化。
- **过验证拿 `x5sec` 回填**：TSDK 维护者称验证通过即下发 x5sec、放进 cookie 即可（#18）；但另有报告称还需同步改 UA，且 Playwright 中"自动、手动都无法通过，可能环境被识别"——对 Playwright 是**负面信号**。
- **换账号无效**（#27）；**换 IP** 方向常见（V2EX 称按 IP 连坐），无成功率数据。
- **降频**是中文资料首位建议，无量化阈值；**`_m_h5_tk` 预热**与 RGV587 无关；**重建 profile** 未找到可靠公开资料。

## 3. 手机 H5 网页版

- `m.goofish.com`：实测 **DNS 不存在（NXDOMAIN）**（第三方博客仍视其为手机分享域名，已过时）。
- `h5.m.goofish.com`：可解析，但根路径是闲鱼自己的 404 页；公开可见用途为商品分享页 `https://h5.m.goofish.com/item?id=...`（[V2EX](https://www.v2ex.com/t/1136121)）。即**不存在 H5 搜索站**。
- `www.goofish.com/search` 在 iPhone UA 下不跳转、无 App 下载门，返回**同一个 PC SPA**（`viewport width=1280`、JS 为 `idle-pc/xy-site`），接口仍是 `...pc.search`（抓页面与 bundle 核实）。
- 接口区分：PC 网页用 `mtop.taobao.idlemtopsearch.pc.search`（`h5api.m.goofish.com`）；**App 用 `mtop.taobao.idlemtopsearch.search`**（`g-acs.m.goofish.com/gw/`），需 `x-sgext`/`x-mini-wua`/`x-umt`/`x-sign`（[Faithlv 笔记](https://www.faithlv.top/posts/%E9%97%B2%E9%B1%BCapp%E9%80%86%E5%90%912%E6%8E%A5%E5%8F%A3%E5%8F%82%E6%95%B0%E5%88%86%E6%9E%90/)）。
- 需登录：goofish-client 要求带 `cookie2` 才能调 mtop（[文档](https://11273.github.io/goofish-client/guide/authentication.html)）；匿名搜索是否可用**未找到可靠公开资料**。

## 4. 原生推送能否替代

原生"关注上新"开关存在（设置 → 消息通知 → 关注上新，[百度经验](https://jingyan.baidu.com/article/fc07f98989cdf153fee51924.html)），但只作用于**你关注的商品/卖家**；降价提醒针对**已收藏商品**（[小米之家](https://m.mizhijia.net/wz/762063.html)）；求购是发一条求购信息（[卖家网](https://www.maijiaw.com/article/610444)），知乎另有"求购是否已取消"的讨论。**任意关键词上新提醒**未见原生支持的可靠资料，反证是第三方监控工具以此为卖点（[voltwake/xianyu-monitor](https://github.com/voltwake/xianyu-monitor)）。**推测**：原生推送无法覆盖此退路。

## 5. x5sec：定义、时效、前提

定义：通过阿里安全验证后下发的校验 Cookie，配合 `bx-pp`/`bx-ua`/`bx-et`/`slidedata`/`x5secdata` 完成校验（[CSDN](https://blog.csdn.net/zhengjianyang1/article/details/148844383)）。有效期：V2EX 网友称"通过滑块后才能获取，且只有半小时时间"（2019 年社区说法，[527879](https://www.v2ex.com/t/527879)）；goofish-client 亦称其"具有时效性，需定期更新"。**未见官方时长**。前提：须先被 punish（`x5secdata`、`x5step=2&action=captcha`），baxia 会做环境指纹检测；有报告称 Playwright 中连手动验证都过不去、x5sec 需与 UA 匹配（#18）。按要求不提供过验证码实操。

**未找到可靠公开资料**：RGV587 官方定义；重建 profile 换指纹成功率；降频安全阈值；x5sec 官方有效期；原生"任意关键词推送"是否存在；移动端匿名搜索可用性。
